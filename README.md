# 📋 计划卡片 - Vue 3 + Pinia 项目

一个使用 Vue 3 组合式 API 和 Pinia 状态管理的现代化计划管理应用。

## 🚀 功能特性

- ✅ **Vue 3 + `<script setup>`** - 使用最新的组合式 API 语法
- 🗄️ **Pinia 状态管理** - 轻量级、类型安全的状态管理
- 📊 **实时统计** - 计划状态统计面板
- 🎨 **现代化 UI** - 响应式设计，美观的渐变效果
- 📱 **移动端适配** - 完美支持手机和平板设备
- 🔄 **状态切换** - 一键切换计划状态（待办→进行中→已完成）
- 🏷️ **优先级管理** - 支持高、中、低优先级分类
- 🗑️ **计划删除** - 轻松删除不需要的计划

## 🛠️ 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **Pinia** - Vue 官方推荐的状态管理库
- **Vite** - 快速的前端构建工具
- **@vueuse/core** - Vue 组合式 API 工具集

## 📦 安装依赖

```bash
npm install
```

## 🎯 核心功能

### 状态管理 (Pinia)
- 使用组合式 API 风格的 Pinia store
- 响应式状态管理
- 计算属性自动更新统计数据

### 计划管理
- 添加新计划
- 切换计划状态
- 删除计划
- 优先级分类

### 响应式设计
- 桌面端网格布局
- 移动端单列布局
- 流畅的动画效果

## 🎨 设计亮点

- 渐变背景和卡片阴影
- 状态颜色编码
- 优先级左边框指示
- 悬停动画效果
- 现代化表单设计

## 📱 使用方法

1. **查看统计** - 顶部面板显示计划总数和各状态数量
2. **添加计划** - 填写标题、描述和优先级后点击添加
3. **管理计划** - 点击状态图标切换状态，点击垃圾桶删除
4. **优先级** - 通过左边框颜色和标签识别优先级

## 🔧 自定义配置

可以在 `src/stores/planStore.js` 中修改：
- 初始计划数据
- 状态类型
- 优先级设置
