# 新首页设计规制

## 设计原则

### 1. 图标使用规范
- **禁用表情符号**：页面不使用表情符号
- **第三方图标库**：统一使用第三方图标库（如 FontAwesome、Lucide 等）

### 2. 组件化架构
- **模块组件化**：所有页面模块都必须组件化
- **组件复用**：确保组件的可复用性和独立性

### 3. 布局设计规范
- **移动端优先**：模拟手机显示效果
- **rem单位**：统一使用 rem 单位进行布局
- **禁用媒体查询**：不使用媒体查询，直接适配移动端尺寸

### 4. 底部输入框规范
- **全局显示**：底部输入框在所有组件中都必须显示
- **微信风格**：参考微信的底部输入框设计
- **固定定位**：底部输入框固定在页面底部
- **语音对话功能**：
  - 支持语音输入和文字输入
  - 可通过对话修改所有卡片数据
  - 例：说话修改闹钟时间"把闹钟改成7:50"
- **智能交互**：
  - 识别用户意图，直接操作对应卡片
  - 支持自然语言命令
  - 实时反馈操作结果

### 5. 内容区域规范
- **高度计算**：核心内容区域高度 = 视窗高度 - 底部输入框高度
- **滚动区域**：内容超出时在内容区域内滚动

### 6. 交互功能规范
- **下滑展开**：实现从顶部向下滑动的功能
  - 新内容覆盖首页内容
  - 底部输入框和按钮保持显示
  - 支持返回到首页状态
- **手势操作**：
  - 顶部滑动区域：左右滑动切换梦想块
  - 从顶部下滑：展开超时间维度层
  - 返回手势：从展开层返回首页

## 首页功能详细说明

### 顶部滑动区域（梦想块区域）
- **块数量配置**：总共无限的块，默认同时显示3个块
- **视觉层次**：
  - **中间的块**：稍微大一些（约1.2倍），作为焦点，完全不透明
  - **左右两边的块**：标准大小，透明度约70%，形成层次感
  - **边缘块**：如有更多块，边缘部分半隐藏显示
- **滑动交互**：
  - 支持左右滑动切换
  - 滑动会将中间的块进行替换
  - **吸附效果**：滑动释放后自动吸附到最近的居中位置
  - **阻尼效果**：滑动边界时有弹性回弹
  - 可使用第三方滑动库（如Swiper.js）实现
- **内容展示**：
  - 每个块显示**文字标题**和**简短描述**
  - 代表用户的不同梦想（如：孩子考哈佛、事业发展、健康管理等）
  - **状态指示**：可显示进度条或状态图标
- **联动效果**：当前居中的块决定下方卡片区域的显示内容

### 卡片区域设计
- **位置**：位于顶部滑动区域下方，占据剩余可视区域
- **布局方式**：网格布局，支持不同尺寸卡片（1x1, 2x1, 1x2等）
- **卡片类型**：
  - **通用固定卡片**：时间、天气、闹钟、日历、提醒等常用功能卡片
  - **特定场景卡片**：根据选中的梦想块动态显示相关内容
    - 学业相关：考试倒计时、学习进度、成绩跟踪
    - 健康相关：运动记录、饮食追踪、体检提醒
    - 事业相关：项目进度、会议安排、目标完成度
- **显示逻辑**：
  - **混合显示**：通用卡片和特定场景卡片同时显示
  - **动态调整**：根据顶部选中的块内容，动态调整特定卡片的显示内容和优先级
  - **可配置性**：用户可设置特定卡片转换为通用卡片，或调整显示优先级
- **卡片状态**：
  - **实时更新**：卡片数据实时同步
  - **交互反馈**：点击卡片有相应的交互反馈
  - **语音控制**：通过底部输入框语音修改卡片内容

### 下滑展开功能（超时间维度内容层）
- **触发方式**：从顶部向下滑动
- **维度概念**：
  - **首页维度**：基于当前时间、当前地点的实时显示（现实维度）
  - **展开维度**：超越时间维度的更高维度展示空间
- **展示内容**：
  - **时间跨度**：整合过去、现在、未来的全维度信息
  - **深度信息**：不局限于当前状态，包含历史轨迹、趋势分析、未来规划
  - **关联性展示**：显示梦想与其他要素的深层连接
- **内容特性**：
  - **历史回顾**：该梦想的发展历程、关键节点
  - **现状分析**：当前进展、影响因素、资源状况
  - **未来展望**：预期目标、路径规划、可能性分析
  - **多维关联**：与其他梦想、生活领域的交叉影响
- **编辑模式**：
  - **直接修改**：可直接点击编辑页面内容
  - **对话修改**：通过底部输入框的对话功能修改设置
  - **双重支持**：同时支持手动操作和语音对话两种方式
- **交互保持**：底部输入框和按钮在展开时仍然显示
- **数据同步**：修改后的内容实时同步到首页对应卡片
- **视觉体现**：通过设计语言体现维度差异（如色彩、布局、动效等）

## 技术实现要点

### CSS 布局结构
```
├── 主容器 (100vh)
│   ├── 内容区域 (calc(100vh - 底部高度))
│   │   ├── 现实维度层（首页）
│   │   │   ├── 顶部滑动区域（梦想块）
│   │   │   └── 卡片展示区域
│   │   │       ├── 通用固定卡片（当前时间地点）
│   │   │       └── 特定场景卡片（实时状态）
│   │   └── 超时间维度层（下滑展开）
│   │       ├── 历史轨迹展示区
│   │       ├── 现状分析区域
│   │       ├── 未来规划区域
│   │       └── 多维关联图谱
│   └── 底部固定区域
│       └── 输入框组件（跨维度通用）
```

### 组件层级规划
- **全局布局组件**
- **底部输入框组件**（跨维度通用）
- **现实维度层组件**（首页）
  - **顶部滑动区域组件**（梦想块轮播）
    - 梦想块组件
    - 滑动控制器
  - **卡片区域组件**
    - 通用卡片组件（时间、天气、闹钟等）
    - 特定场景卡片组件
    - 卡片管理器
- **超时间维度层组件**（下滑展开）
  - **历史轨迹组件**
    - 时间线展示
    - 关键节点标记
  - **现状分析组件**
    - 进展仪表板
    - 影响因素分析
  - **未来规划组件**
    - 目标路径图
    - 可能性预测
  - **多维关联组件**
    - 关系图谱
    - 交叉影响分析
- **维度切换控制组件**

## 开发规范

### 基础开发规范
1. 所有组件使用 Vue 3 Composition API
2. 样式使用 SCSS 预处理器
3. 图标统一管理，建立图标配置文件
4. 组件间通信使用 Pinia 状态管理
5. 遵循移动端触摸交互规范

### 维度差异体现规范
6. **视觉层次区分**：
   - 现实维度层：明亮、实时、具体的视觉风格
   - 超时间维度层：深邃、抽象、时间感的视觉风格
7. **动效设计区分**：
   - 现实维度：快速、直接的交互反馈
   - 超时间维度：缓慢、渐进的过渡效果
8. **数据展示区分**：
   - 现实维度：实时数据、当前状态
   - 超时间维度：历史数据、趋势分析、预测数据
9. **交互模式区分**：
   - 现实维度：快速操作、即时反馈
   - 超时间维度：深度探索、多层次信息展示

1. **第三方滑动库选择**：确定使用Swiper.js还是其他库
2. **语音识别服务**：确定使用哪种语音识别API（Web Speech API、百度、讯飞等）
3. **数据存储方案**：本地存储策略和云端同步机制
4. **梦想块数据结构**：定义梦想块的数据模型和字段
5. **卡片插件机制**：如何支持自定义卡片和第三方卡片扩展
6. **维度切换动画**：具体的转场动画实现方案
7. **多维关联算法**：如何计算和展示梦想间的关联性
8. **响应式适配**：虽然主要针对移动端，但需要考虑不同屏幕尺寸的适配
9. **性能优化策略**：大量卡片和复杂动画的性能优化方案
10. **无障碍访问**：支持屏幕阅读器等无障碍功能的实现
