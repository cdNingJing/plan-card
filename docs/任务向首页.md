# 任务向首页设计文档

## 设计概述
创建一个移动端首页，通过连贯的滑动手势实现屏幕间的自然切换，以卡片化的方式展示用户的梦想和任务。

## 核心功能需求

### 1. 顶部梦想展示区
- 显示3个核心梦想：家庭、事业、社交
- 顶部只显示中文文字，不显示其他元素
- 从右到左排列：第一个（最右侧）为当前选中状态
- 选中的梦想文字需要放大显示，字体比其他的大
- 支持左右滑动切换梦想
- **关联动效**：当前选中的梦想文字与页面内容有联动关系

### 2. 内容卡片区域
- 下方显示与当前激活梦想相关的卡片
- 通过左滑可以切换到另一个梦想的内容
- 内容切换时有流畅的移动过渡动画
- 排在第一个的title需要加大并放在靠右的第一个位置
- **临时显示方式**：卡片暂时使用背景色块代替，便于布局调试

### 3. 屏幕切换交互
- 所有页面交互通过移动手势实现
- 当前屏幕1通过下滑可以切换到屏幕2
- 屏幕之间的切换需要连贯流畅的动画效果
- 手势需要自然，跟随用户的滑动进度
- **梦想文字联动效果**：
  - 当用户下滑时，当前选中的梦想文字跟随滑动向下移动
  - 文字在滑动过程中保持可见，创造连贯的视觉体验
  - 最终文字固定在下方页面的适当位置
  - 起到串联上下卡片内容的桥梁作用，增强页面层次感

### 4. 底部圆角块区域
- 在页面最底部添加一个圆角的背景块
- **临时显示方式**：使用纯色背景代替，便于布局测试
- 圆角设计保持与整体UI风格一致
- 为后续功能扩展预留空间
- 可能用于显示操作按钮、状态信息或其他交互元素

### 2. 手势交互实现
- 使用Touch事件处理滑动手势
- 实现手势跟随的实时动画效果  
- 支持惯性滑动和弹性回弹
- 区分水平滑动（切换梦想）和垂直滑动（切换屏幕）
- **梦想文字联动实现**：
  - 监听垂直滑动进度，实时计算文字位置
  - 使用transform: translateY()实现文字跟随滑动
  - 设置关键帧节点，控制文字从顶部移动到底部的路径
  - 在滑动完成后，文字固定在目标位置作为页面标题

### 3. 动画效果
- 梦想切换时的缩放和透明度变化
- 卡片内容的左右滑动切换
- 屏幕间的垂直切换动画
- **梦想文字联动动画**：
  - 文字跟随滑动的平滑移动效果
  - 在移动过程中可能包含轻微的缩放或透明度变化
  - 到达目标位置时的缓动效果
  - 与背景内容的层次关系处理
- 所有动画使用easing函数确保流畅性

### 4. 响应式布局
- 适配不同尺寸的移动设备
- 确保在各种屏幕分辨率下都有良好的显示效果
- 优化触摸区域大小，确保手势识别准确

### 5. 临时布局实现
- **卡片占位符**：使用不同颜色的背景块代替实际卡片内容
- **底部圆角块**：使用简单的圆角矩形背景色块
- 便于快速验证布局结构和交互逻辑
- 后续可以逐步替换为实际的功能组件

## 样式设计

### 1. 视觉层次
- 选中的梦想使用较大字体显示在最右侧
- 非选中梦想使用较小字体，透明度降低
- 顶部区域只显示中文文字，简洁明了
- 第一个title需要特殊处理：加大显示并放在右侧第一个位置
- **联动文字视觉设计**：
  - 移动过程中文字保持清晰可读
  - 在不同背景上确保足够的对比度
  - 文字大小在移动过程中可能有适当调整
  - 最终位置的文字样式与页面整体风格协调

### 2. 颜色方案
- 使用温暖的渐变色彩
- 不同梦想使用不同的主题色
- 保持整体视觉的一致性和美观性
- **临时配色方案**：dream-header
  - 卡片占位符：使用浅灰色、浅蓝色、浅绿色等区分不同类型
  - 底部圆角块：使用中性色背景，如浅灰色或白色
  - 确保所有占位符颜色对比度适中，不影响文字阅读

### 3. 动画参数
- 切换动画时长：300-500ms
- 使用cubic-bezier缓动函数
- 适当的延迟和交错效果

## 用户体验目标
- 直观的手势操作，无需学习成本
- 流畅的动画效果，无卡顿感
- 清晰的视觉反馈，用户明确当前状态
- 快速的响应速度，操作即时生效
- **增强的连贯性体验**：
  - 通过梦想文字的联动效果，让页面切换更加自然
  - 创造连续的视觉叙事，增强用户的沉浸感
  - 文字作为视觉锚点，帮助用户理解页面层次关系
  - 提供更强的空间感和深度感，优化整体交互体验

手机屏幕从左上角（顶点）出发，有三条以左上角为中心的圆形分割线，这些分割线会旋转。下面我把这个场景做成一个可落地的设计说明与实现蓝图：视觉概念 → 交互语义（每圈代表什么） → 手势/动画细节 → 可视化呈现 & 代码骨架 → 无障碍与性能提示 → 三个创意玩法映射到你的用例。你可以直接拿这份去给前端/产品做原型或实现 demo。

核心视觉概念（一句话）
把屏幕当作一个以左上角为“恒星”的小宇宙，三条同心（注意不是严格同心，而是同“中心点”）圆弧做为“环”，围绕左上顶点旋转，环的角度/对齐状态就是用户的选择 / 时间或概率的表达。

对应语义（建议）
内圈（最靠近左上）：过去（或根基、历史决定）

中圈：现在（当前状态 / 关键参数）

外圈：未来（可能的结果 / 目标强度）

环的旋转角度可以映射到不同含义（选一个或组合）：

角度 → 不同“切片”或“扇区”，每个扇区代表一种策略/值（例如：多/中/少、A/B/C方案）。

角度差（环之间的相对角度） → 因果强弱（过去与现在对未来的影响）

旋转速度 /惯性 → 代表决策的“冲动度”或不确定性
