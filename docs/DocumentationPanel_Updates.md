# DocumentationPanel 页面更新总结

## 概述

根据 `FE_API_GUIDE_v1.md` 文档，我们对 `DocumentationPanel.vue` 页面进行了全面更新，添加了新的 API 功能支持。

## 🔄 主要更新内容

### 1. 新增操作按钮

在操作按钮区域添加了以下新功能按钮：

- **重排序搜索按钮**: 提供高级重排序搜索功能
- **操作历史按钮**: 查看内容管理操作历史
- **系统状态按钮**: 检查系统健康状态

### 2. 增强搜索功能

#### 2.1 高级搜索选项
在搜索对话框中添加了以下高级选项：

- **包含图上下文**: 启用图数据库上下文扩展
- **启用重排序**: 使用 Cerebras LLM 进行智能重排序
- **生成推理合成**: 生成推理分析和洞察
- **最小相关性分数**: 设置相关性阈值 (0.0-1.0)

#### 2.2 重排序搜索对话框
新增专门的重排序搜索对话框，包含：

- 搜索关键词输入
- 集合选择
- 结果数量限制
- 重排序策略选择 (Cerebras LLM)
- 详细解释选项

### 3. 操作历史功能

#### 3.1 操作历史对话框
新增操作历史查看功能：

- **操作类型过滤**: 按编辑/删除操作过滤
- **显示数量控制**: 自定义显示记录数量
- **操作详情显示**: 
  - 操作类型 (编辑/删除)
  - 操作时间
  - 集合名称
  - 块ID
  - 处理时间
  - 操作状态

#### 3.2 历史记录样式
- 编辑操作: 蓝色标签
- 删除操作: 橙色标签
- 成功状态: 绿色
- 失败状态: 红色

### 4. 系统健康检查

#### 4.1 健康检查功能
新增系统状态检查功能：

- 检查系统健康状态
- 获取系统版本信息
- 显示运行时间
- 显示活跃用户数
- 显示总集合数

#### 4.2 系统信息获取
- 获取系统基本信息
- 显示服务状态
- 显示文档链接

### 5. API 方法更新

在 `knowledgeApi.js` 中添加了以下新方法：

#### 5.1 搜索相关
- `search()`: 增强的搜索方法，支持所有新参数
- `rerankSearch()`: 专门的重排序搜索方法
- `getSearchSuggestions()`: 获取搜索建议

#### 5.2 内容管理
- `getChunkDetails()`: 获取块详情
- `editChunk()`: 编辑块内容
- `deleteChunk()`: 删除块

#### 5.3 操作历史
- `getOperationHistory()`: 获取操作历史

#### 5.4 系统信息
- `healthCheck()`: 系统健康检查
- `getSystemInfo()`: 获取系统信息

### 6. 用户界面改进

#### 6.1 新增样式
- 高级搜索选项样式
- 操作历史列表样式
- 新按钮样式 (重排序、历史、健康检查)

#### 6.2 交互优化
- 自动加载操作历史
- 实时显示操作结果
- 友好的错误提示

### 7. 数据结构更新

#### 7.1 表单数据结构
```javascript
// 搜索表单
searchForm: {
  query: '',
  collectionName: '',
  limit: 5,
  includeGraphContext: false,
  includeReranking: false,
  includeReasoning: false,
  scoreThreshold: 0.0
}

// 重排序表单
rerankForm: {
  query: '',
  collectionName: '',
  limit: 5,
  rerankingStrategy: 'cerebras_llm',
  includeExplanation: false
}

// 历史表单
historyForm: {
  operationType: '',
  limit: 50
}
```

#### 7.2 状态管理
- `showRerankDialog`: 重排序对话框显示状态
- `showHistoryDialog`: 历史对话框显示状态
- `isReranking`: 重排序加载状态
- `isLoadingHistory`: 历史加载状态
- `operationHistory`: 操作历史数据

## 📋 使用指南

### 1. 基础搜索
1. 点击"搜索"按钮
2. 输入搜索关键词
3. 选择目标集合
4. 设置结果数量
5. 点击搜索

### 2. 高级搜索
1. 点击"搜索"按钮
2. 输入搜索关键词
3. 配置高级选项：
   - 启用图上下文
   - 启用重排序
   - 启用推理合成
   - 设置相关性阈值
4. 点击搜索

### 3. 重排序搜索
1. 点击"重排序搜索"按钮
2. 输入搜索关键词
3. 选择集合和参数
4. 选择重排序策略
5. 点击重排序搜索

### 4. 查看操作历史
1. 点击"操作历史"按钮
2. 选择操作类型过滤
3. 设置显示数量
4. 查看操作记录详情

### 5. 系统状态检查
1. 点击"系统状态"按钮
2. 查看系统健康信息
3. 检查性能指标
