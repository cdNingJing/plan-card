# 购物场景测试指南

## 概述

本指南将帮助您测试购物场景中的新功能，特别是 `selected-products` 卡片的集成。

## 测试环境准备

1. 确保项目已正确启动
2. 确保所有依赖已安装
3. 确保 API 接口正常工作

## 测试步骤

### 1. 创建购物场景

1. 打开应用，进入对话界面
2. 输入购物相关的需求，例如：
   - "我想给妈妈买园艺相关的礼物，预算500元以内"
   - "帮我搜索适合爸爸的运动装备"
   - "推荐一些适合孩子的玩具"

3. 观察系统是否正确识别为购物场景（gift）

### 2. 验证卡片创建

创建购物场景后，应该包含以下卡片：
- `basic-info` - 基础信息卡片
- `shop` - 商品列表卡片
- `selected-products` - 已选商品卡片 ⭐ **新增**
- `profile` - 用户画像卡片
- `tips` - 购物提示卡片

### 3. 测试商品选择功能

1. 在 `shop` 卡片中：
   - 等待商品数据加载完成
   - 点击商品卡片进行选择/取消选择
   - 观察商品是否显示选中状态（蓝色边框和勾选标记）

2. 在 `selected-products` 卡片中：
   - 观察已选商品是否正确显示
   - 验证商品数量统计是否正确
   - 检查总价计算是否准确

### 4. 测试商品管理功能

在 `selected-products` 卡片中测试：

1. **单个商品移除**：
   - 点击商品右上角的 "×" 按钮
   - 验证商品是否从列表中移除
   - 检查数量统计是否更新

2. **批量清空**：
   - 点击 "清空" 按钮
   - 确认弹窗提示
   - 验证所有商品是否被清空

3. **商品详情查看**：
   - 点击商品的 "查看" 按钮
   - 验证是否在新窗口打开商品链接

### 5. 测试购买功能

在 `selected-products` 卡片中测试：

1. **立即购买**：
   - 点击 "立即购买" 按钮
   - 验证购买事件是否正确触发
   - 检查控制台日志输出

2. **批量添加到购物车**：
   - 点击 "全部加入购物车" 按钮
   - 验证购物车事件是否正确触发
   - 检查本地存储中的购物记录

### 6. 测试数据同步

1. **跨卡片同步**：
   - 在 `shop` 卡片中选择商品
   - 观察 `selected-products` 卡片是否实时更新
   - 在 `selected-products` 卡片中移除商品
   - 观察 `shop` 卡片中的选中状态是否同步更新

2. **本地存储同步**：
   - 刷新页面
   - 验证已选商品数据是否保持
   - 检查 localStorage 中的数据是否正确

### 7. 测试响应式设计

1. **桌面端**：
   - 验证卡片布局是否正常
   - 测试全屏模式功能

2. **移动端**：
   - 调整浏览器窗口大小
   - 验证响应式布局是否正常
   - 测试触摸操作是否流畅

### 8. 测试错误处理

1. **网络错误**：
   - 模拟网络断开
   - 验证错误提示是否显示
   - 测试重试功能

2. **数据异常**：
   - 手动修改 localStorage 中的异常数据
   - 验证组件是否能正确处理异常
   - 检查错误日志输出

## 常见问题排查

### 1. 卡片不显示

**可能原因**：
- 组件导入路径错误
- 卡片类型映射缺失
- 模板渲染条件错误

**排查步骤**：
1. 检查控制台是否有错误信息
2. 验证组件是否正确导入
3. 检查 `getCardComponent` 函数中的映射

### 2. 数据不同步

**可能原因**：
- localStorage 操作失败
- 事件监听器未正确设置
- 数据格式不一致

**排查步骤**：
1. 检查 localStorage 中的数据
2. 验证事件监听器是否正确注册
3. 检查数据格式是否符合预期

### 3. 样式显示异常

**可能原因**：
- CSS 类名冲突
- 样式文件未正确加载
- 响应式断点设置错误

**排查步骤**：
1. 检查浏览器开发者工具中的样式
2. 验证 CSS 类名是否正确
3. 测试不同屏幕尺寸下的显示效果
