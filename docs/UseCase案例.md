## 🚀 用例 1：「紧急商务行程统筹」

### 初始指令
> “我明天下午临时要去纽约开客户会”

### 流程拆解

#### 阶段一：信息密集型界面（即时展示）
单卡片显示：
- 下一个可选航班（含你的座位偏好）
- 客户地点附近酒店（带会员等级信息）
- 天气预报及行李建议
- 机场到客户地点的 Uber 预估费用
- 冲突日程提醒及重排建议

#### 阶段二：扩展为 Planner UI
**航班卡片**
- 自动筛选中午前抵达的航班
- 考虑用户航空会员等级
- 显示 WiFi 是否可用（知道你要在路上工作）

**酒店卡片**
- 离开会地点可步行
- 带健身房（偏好设定）
- 支持延迟退房

**准备事项卡片**
- 根据天气和会议类型自动生成行李清单
- 自动从邮件中提取相关资料
- 出差打车发票提醒

**通讯管理卡片**
- 自动草拟邮件调整冲突行程
- 向配偶发出出差通知
- 设置自动回复

#### 跨卡片上下文联动
- 换航班 → 酒店入住时间自动调整
- 换酒店 → 出租车费用自动重算
- 加一天行程 → 所有卡片实时联动更新

#### 验证点
- ✓ CP#1：指令正确生成多卡片 UI
- ✓ CP#2：“加个红眼航班”→ 所有卡片跟随更新
- ✓ CP#3：信息在 4+ 卡片间无缝流动
- ✓ CP#4：记住“喜欢靠走道座位”偏好
- ✓ CP#5：自动应用过往出差偏好
- ✓ CP#6：“一键预订”由智能代理执行

## 💡 用例 2：「房产多物业运营总览」

### 初始指令
> “看看我名下房产最近运营情况”

### 流程拆解

#### 阶段一：信息密集型概览
紧凑型仪表盘：
- 本月现金流
- 物业入住率
- 维修提醒
- 租客留言
- 市场租金对比

#### 阶段二：智能展开
**物业经营卡（每个物业单独一张）**
- 单个物业收支情况
- 租客支付记录
- 维修排期
- 水电气使用趋势

**操作中心卡**
- “123 Oak St 租客逾期” → 草拟催款信
- “456 Pine 空调保养” → 安排常用维修工
- “市场租金上涨 5%” → 自动生成涨租信

**财务规划卡**
- 税务优化建议
- 再融资机会
- 投资房产推荐

#### 智能上下文感知示例
- 自动识别物业地址、租客、维修工、税务情况
- 查询：“Oak Street 那套呢？” → 定位并展开该物业
- 维护状态变更 → 相关财务预测实时更新

#### 验证点
- ✓ CP#1：复杂指令 → 多卡 Planner
- ✓ CP#2：“只看空置房” → 即时筛选
- ✓ CP#3：审批维修 → 预算同步更新
- ✓ CP#4：学习常用维修工及费用
- ✓ CP#5：识别优先级物业
- ✓ CP#6：“群发续租信”代理执行

## 🧪 Web 团队测试框架

### ✅ 每个用例需验证：

#### 速度指标
- 初始 UI 生成：< 2 秒
- 卡片展开：< 500ms
- 上下文联动：< 1 秒
- 焦点条更新：< 200ms

#### 准确性指标
- 正确 UI 类型：93%以上
- 上下文选择相关性：90%以上
- 信息完整无缺漏
- 任务完成率：80%以上

#### 用户惊喜指标
- 10 秒内触发“Wow”瞬间
- 操作步骤比传统 App 减少 70%
- 自动发现用户未主动请求信息
- 节省时间：比传统 App 快 10 倍

### 📅 日常测试安排
- 周一：商务行程（测试速度&复杂性）
- 周二：房产管理（测试数据密度）
- 周三：老人照护（测试同理心&稳定性）
- 周四：新品发布（测试创意与协作）
- 周五：家庭节能（测试学习与优化）

### Bug 优先级
1. **致命**：中断流程/丢数据
2. **高**：错误 UI/上下文联动慢
3. **中**：缺少上下文/次优推荐
4. **低**：视觉问题/边缘场景
