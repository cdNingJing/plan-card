# 会议延期功能演示

## 功能概述

会议延期功能允许用户通过自然语言表达（如"推迟到明天"）自动处理会议延期流程，包括：
- 自动识别延期意图
- 更新日历事件
- 发送延期通知邮件
- 更新本地会议信息

## 使用场景

### 场景1：简单延期
**用户输入：** "会议推迟到明天"

**系统响应：**
1. 识别延期意图
2. 显示会议延期卡片
3. 自动计算明天的时间
4. 执行延期操作

### 场景2：带原因的延期
**用户输入：** "由于时间冲突，会议延期到后天"

**系统响应：**
1. 识别延期意图和原因
2. 显示延期卡片，包含延期原因
3. 在通知邮件中包含延期原因

## 技术实现

### 1. 意图识别
- 关键词匹配：推迟、延期、延迟、改期、延后
- 时间识别：明天、后天、下周、具体日期
- 原因提取：由于、因为、时间冲突等

### 2. 卡片流程
```
用户输入 → 意图识别 → 生成延期卡片 → 确认延期 → 执行操作 → 显示结果
```

### 3. API接口
- `POST /api/meeting-postpone` - 处理会议延期
- `POST /api/calendar-update` - 更新日历事件
- `POST /api/meeting-postponement-notification` - 发送延期通知
